# 🤖 AI Fundamentals Course 2026-2

### From Python & Data to Intelligent Systems

Welcome to the **AI Fundamentals** course repository.

This repository contains the **lectures, notebooks, exercises, projects, datasets, and practical activities** developed throughout the course to introduce the fundamental concepts behind Artificial Intelligence.

> **Learn the concepts. Build the models. Understand the intelligence.**

---

## 🎯 Course Overview

Artificial Intelligence is more than algorithms and models.

In this course, we will explore the foundations required to understand, develop, and apply AI systems—from programming and data preparation to machine learning, neural networks, and intelligent agents.

```text
Python
   ↓
Data
   ↓
Algorithms
   ↓
Machine Learning
   ↓
Neural Networks
   ↓
Intelligent Systems
   ↓
Real-World AI Applications
```

---
